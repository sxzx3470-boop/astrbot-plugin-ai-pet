# AI宠物养成插件

[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![AstrBot](https://img.shields.io/badge/AstrBot-plugin-blue.svg)](https://github.com/Soulter/AstrBot)

在 QQ 群里养一只 AI 宠物！支持喂食、互动、好感度、情绪系统、等级成长，精美的状态卡片展示。

## ✨ 特性

- 🍽️ **10种食物** — 喂食降低饥饿度，吃最爱食物有额外加成
- ✋ **5种互动** — 抚摸、抱抱、玩耍、聊天、训练
- 💕 **好感度系统** — 互动越多越粘人
- 😊 **10种情绪** — 随数值动态变化
- 📊 **状态卡片** — 精美的文字卡片展示
- 🏆 **10级称号** — 宠物蛋到至尊级
- ⏰ **时间衰减** — 不互动宠物会变饿
- 👥 **多用户** — 每人独立宠物，数据持久化，还能自己改名



## 📦 安装

1. 下载本插件，放入 AstrBot 的 `addons/` 目录
2. 重启 AstrBot
3. 在 QQ 群发送 `/pet` 开始养宠物！

## 🎮 命令

| 命令 | 说明 |
|------|------|
| `/pet` | 查看指令 |
| `/状态` | 查看你的宠物状态 |
| `/改名 <名字>` | 给你的宠物改名字 |
| `/喂食 <食物>` | 喂宠物（苹果/蛋糕/寿司/冰淇淋/肉/饼干/牛奶/鱼/糖果/蔬菜） |
| `/抚摸` | 抚摸宠物 |
| `/抱抱` | 抱抱宠物 |
| `/玩耍` | 和宠物玩耍 |
| `/睡觉` | 和宠物睡觉 |
| `/醒来` | 唤醒宠物 |
| `/训练` | 训练宠物 |
| `/好感 [@某人]` | 查看宠物对某人的好感卡片 |
| `/pet help` | 帮助信息 |

## ⚙️ 配置（可选）

插件支持通过 AstrBot 面板的插件配置修改：

- `default_pet_name` — 新宠物的默认名字（默认：小宠物）
- `allow_rename` — 是否允许用户 `/改名`（默认：true）
- `cleanup_days` — 自动清理超过 N 天未互动的存档（默认：30，0 为不清理）

## 📂 数据结构

宠物数据存储在 `data/ai_pet/pets.json`，每个用户独立保存。
